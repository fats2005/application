# Twenty8-Production Coding Job Application

## Included
- Responsive HTML application form
- Full name, country, email, mobile number and gender
- CV upload with PDF/DOC/DOCX and 5 MB client-side validation
- Four-step application process
- Settings panel in the top-right
- Live application progress percentage
- Application deadline and countdown
- WhatsApp admin assistance and feedback buttons
- Dark/light theme
- Blurred coding-file background
- Review page before submission

## Run
Open `index.html` in a browser.

## Important
This package is a front-end demo. The submit button validates the application locally but does not upload the CV to a server or send an email. For production use, connect the form to a secure backend/database and file-storage service.

## Changing the deadline
Edit the `deadline` value near the top of `js/app.js`.
